## 1. Proposal — Re-Architecture TMS thành L&D Training Platform

### Target Architecture

Modular monolith, MongoDB giữ tạm, PostgreSQL là target dài hạn, React/Vite giữ nguyên.

Domains mới:

| Domain | Mục đích | Mapping hiện tại |
|--------|----------|-----------------|
| `Identity` | Auth, MFA, session, role/capability | `server/middleware/auth.js`, `server/services/authService.js` |
| `People` | Employee, learner profile, department | `server/models/User.js`, `server/controllers/userController.js` |
| `Learning Catalog` | Program/course template, category, policy | `server/models/LearningProgram.js` (đã làm) |
| `Cohort` | Một lần triển khai chương trình | `server/models/Class.js` (legacy), `/api/learning/cohorts` (đã làm) |
| `Learning Group` | Nhóm học/PIC/leader | `server/models/Team.js` (legacy) |
| `Enrollment` | Learner tham gia cohort/group | `server/models/Enrollment.js` (legacy) |
| `Session` | Buổi học/sự kiện đào tạo | `server/models/Schedule.js` (legacy), `/api/learning/sessions` (đã làm) |
| `Attendance` | Điểm danh theo session | `server/models/Attendance.js`, `server/services/attendanceService.js` |
| `Assessment` | Evaluation, result, completion, score | `server/models/Evaluation.js`, `server/controllers/evaluationController.js` |
| `Reporting` | HR export, dashboard, analytics | `server/services/exportService.js`, `server/controllers/dashboardController.js` |
| `Audit & Reconcile` | Audit log, data integrity | `server/models/AuditLog.js`, `server/services/reconcileService.js` |
| `Integrations` | Google Calendar, Sheets, SMTP, cron | Rải rác trong `server/services/` |

### Vocabulary Migration

| Legacy | Target | Status |
|--------|--------|--------|
| `Class` → `Cohort` | Abstraction/DTO qua `/api/learning/cohorts` | ✅ API + DTO |
| `courseName` → `Program` | `LearningProgram` model | ✅ Xong |
| `Team` → `LearningGroup` | Chưa có domain mới | ❌ |
| `Schedule` → `Session` | `/api/learning/sessions` + DTO | ✅ Backend |
| `Evaluation` → `Assessment` | `domains/assessment` (`/api/assessment`) — generic engine v1; legacy `Evaluation` giữ nguyên | 🟡 v1 (engine live, chưa migrate dữ liệu cũ) |

### Policy Concept (in `LearningProgram`)

- `schedulingMode`: `leader_booking`, `admin_scheduled`, `self_enroll`, `nomination` — ✅ **enforced** on all session-create paths (`domains/schedule/scheduling-mode-policy.js`, Pass C)
- `deliveryMode`: `online`, `offline`, `hybrid` — ⚠️ persisted, not enforced
- `completionPolicy`: attendance threshold, required assessment, required feedback — ✅ enforced (`domains/learning/completion`)
- `capacityPolicy`: per-session/per-cohort capacity — ⚠️ persisted, not enforced
- `facilitatorPolicy`: teacher/facilitator assignment and visibility — ⚠️ persisted, not enforced
